start minikube

create namespace:
kubectl create namespace hello

applying original argocd repository:
kubectl apply -n argocd -f https://raw.githubuserconetent.com/argoproj/argo-cd/stable/manifests/install.yaml

port-forward command:
kubectl port-forward svc/argocd-server -n argocd 8080:443 --address 0.0.0.0

get password:
kubectl -n argocd get secret argocd-initial-admin-secret -0 jsonpath="{.data.password}*

Decrypting password:
[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String('password generated from above'))
